# Record terminal

Recreate a real terminal run in HyperFrames. The terminal is an application
replay, not a terminal-shaped text animation.

**REQUIRED REFERENCE:** Read
[`references/terminal-presentation.md`](references/terminal-presentation.md)
before planning or capturing the shot. Complete its runbook and capture gates
before following its pointer to ledger construction and HyperFrames replay.

User-provided terminal, shell, brand, font, or accessibility requirements
replace the default styling as a coherent visual system. The evidence,
event-order, prompt, and seek-safety contract remains unchanged.

Real screen-recorded footage is a separate branch. Use it only when the user
explicitly requests captured footage; otherwise produce the evidence-backed
HyperFrames replay.
