# Third-party assets

- `assets/gsap.min.js`: GSAP 3.15.0, GreenSock. The upstream copyright and license header is retained. Terms: https://gsap.com/standard-license.
- `assets/fonts/noto-*.ttf`: Noto Sans SC, Google Fonts text subsets, SIL Open Font License. License: [notosanssc-OFL.txt](assets/licenses/notosanssc-OFL.txt).
- `assets/fonts/inter-*.ttf`: Inter, Google Fonts text subsets, SIL Open Font License. License: [inter-OFL.txt](assets/licenses/inter-OFL.txt).
- `assets/fonts/space-600.ttf`: Space Grotesk, Google Fonts text subset, SIL Open Font License. License: [spacegrotesk-OFL.txt](assets/licenses/spacegrotesk-OFL.txt).
- `frame.md`: BlockFrame preset specification copied from the installed HyperFrames skill. Upstream design catalog: https://www.hyperframes.dev/design. This is a scene-review example using that preset, not a new preset.

All fonts and the animation runtime are served locally. Playback does not need a font/CDN request.
