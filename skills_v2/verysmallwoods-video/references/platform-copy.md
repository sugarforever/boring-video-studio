# 平台文案 · YouTube + Bilibili

`youtube.md` 和 `bilibili.md` 段落顺序固定、内容当期填。文风走我的写作风格。

## youtube.md

```
## 标题（候选）
«2-3 个候选» - 沿用系列既有口径；钩子可用：数据/数字、系列定位、这期真做才发现的看点

## 简介
«频道会员推广块»   ← YouTube 专用，每期放（SmallWoods 会员）
«个人信息块»       ← 知识星球 / Twitter / Bilibili / 邮箱
«正文简介»         ← 读完来分享的口吻，概述这期
«相关链接»         ← 主题源、上一期、相关仓库、Claude 播放列表
⏱ 章节
0:00 «开场»
m:ss «各大块小节»   ← 见下「章节」
```

## bilibili.md

B 站更精简：**赞助位在第一行**（DMXAPI），不带章节。标题同 YouTube，正文可略压。

```
## 标题（候选）
（同 YouTube）
## 简介
«赞助商（DMXAPI，第一行）»
«个人信息（B 站留一两条）»
«正文简介»
«相关链接»
```

## 章节（大块，不要太细）

**按大段落分，不逐帧分。** 一期 6-8 个大块就够，例如：开场 / 概念 / 为什么 / 主体（多个小点合成一个大块）/ 落地 / 实战 / 收尾。

时间从**成片里的真实语音起点**取（不是估算）：从 `index.html` 的 voice clip（track 10）`data-start` 拿每段绝对秒，格式 `m:ss`；首章 `0:00`（含片头封面那几秒）。改稿重渲后按新时间轴重取。

## 个人信息 / 推广（占位符，发布时判断）

推广/广告/个人信息是**占位符**，按当期有没有推广灵活填。我的常用块（社群/会员/赞助/播放列表）见 memory [[video-promo]]（拿不准就问我，或直接用里面的）。**别每期硬塞满**，核心内容优先。
