# 平台文案 · YouTube + Bilibili

`youtube.md` 和 `bilibili.md` 段落顺序固定、内容当期填。文风基于用户偏好的写作风格。

## youtube.md

```
## 标题（候选）
«2-3 个候选» - 沿用系列既有口径；钩子可用：数据/数字、系列定位、这期真做才发现的看点

## 简介
«频道会员推广块»
«个人信息块»       ← 知识星球 / Twitter / Bilibili / 邮箱 / 等
«正文简介»
«相关链接»         ← 主题源、上一期、相关仓库、播放列表等
⏱ 章节
0:00 «开场»
m:ss «各大块小节»   ← 见下「章节」
```

## bilibili.md

B 站更精简：**赞助位在第一行**，不带章节。标题与正文描述同 YouTube。

```
## 标题（候选）
## 简介
«赞助商»
«个人信息»
«正文简介»
«相关链接»
```

## 章节

基于 SRT 文件，和视频内容结构，生成章节。以内容结构为主体，拆分章节。

## 个人信息 / 推广

推广/广告/个人信息是**占位符**，并不是每期必须的信息。用户的常用信息（社群/会员/赞助/播放列表）来自记忆或上下文。
