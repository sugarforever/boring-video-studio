# 博客 + 推文

## 博客

一篇配套博客，存项目里 `blog.md`。

### 口吻与结构

基于用户偏好的写作风格编写博客。

### frontmatter

```yaml
---
title: "..."          # 带钩子
date: "YYYY-MM-DD"
excerpt: "..."
tags: [...]           # 用规范 tag（Context Engineering / Claude Code / Agent Skills / AI 编程…），别堆同义词
lang: "zh"
cover: "blog-images/blog-cover.png"
---
```

### 配图 = 视频截图

为博客生成一张封面图。

## 推文（X）

一条精简的：

- 开头一句钩子
- 主体用箭头/序号列关键点，可供快速浏览。
- 出处链接（原文）。可选：挂自己的视频链接。
