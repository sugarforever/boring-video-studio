# 视频 · 用 HyperFrames 出片

视频制作采用 /hyperframes Skill，这个核心入口。

## 口播稿

视频制作中的口播稿，按照用户的写作或口播偏好来写。偏好会来自于：
- 上下文
- 记忆
- 会话中可用的风格 Skill

## 旁白来源

旁白音频来源包括：
- 用户自行录制
- TTS 合成

### 用户自行录制

由用户提供音频文件和 SRT 文件。接收到的 SRT 文件，基于口播稿内容校对，核准。

### TTS 合成

支持以下的 TTS 服务：
- HyperFrames 内置的 TTS 服务
- 用户安装的 Skill 提供的 TTS 服务
